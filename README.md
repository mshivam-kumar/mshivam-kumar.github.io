## 🚀 Easy Management System

This portfolio includes a comprehensive management system for easy updates:

### 📝 Quick Updates
```bash
# Update About section
python3 portfolio_manager.py

# Change resume link
python3 update_resume.py "https://new-resume-link.com"

# Add new project
python3 add_project.py

# Update everything from config
python3 quick_update.py
```

### 🔧 Configuration File
All content is managed through `portfolio_config.json`:
- Personal information
- About section text
- Resume link
- Social media links
- Projects array
- Skills, experience, education sections

### 📁 File Structure
```
mshivam-kumar.github.io/
├── portfolio_manager.py      # Interactive management tool
├── project_manager.py        # Project & section management
├── add_project.py           # Quick project addition
├── update_resume.py         # Quick resume update
├── quick_update.py           # Configuration-based updates
├── portfolio_config.json     # All content configuration
├── static/js/main.945f37a7.chunk.js  # Main content (auto-updated)
├── asset-manifest.json       # Asset mappings (auto-updated)
├── index.html               # Main page (auto-updated)
└── README.md                # This file
```
